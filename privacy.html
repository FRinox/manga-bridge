🛡️ Politique de confidentialité — Manga-Bridge Universal

Dernière mise à jour : juillet 2025

Manga-Bridge Universal est une extension Chrome 100% locale qui compare votre collection MangaCollec avec les sites de vente en ligne pour vous éviter d'acheter des mangas que vous possédez déjà. Tout fonctionne en temps réel, sans envoyer aucune donnée en ligne.

Cette extension ne communique avec aucun serveur tiers. Toutes les données sont stockées localement sur votre appareil, dans le stockage isolé de l'extension (chrome.storage.local).

1. Données collectées

L'extension stocke uniquement les données suivantes, exclusivement en local :

  • Pseudo MangaCollec — saisi manuellement par vous, utilisé pour récupérer votre collection.
  • Base de correspondance — liste des mangas de votre collection (titre, éditeur, tomes, édition), synchronisée depuis MangaCollec.
  • Base annexes — entrées ajoutées manuellement par vous pour des titres non présents sur MangaCollec.
  • Éditeurs et genres appris — récupérés depuis MangaCollec lors d'une synchro, stockés localement.
  • Sélecteurs configurés — règles CSS apprises pour chaque site marchand que vous configurez (titre, case, tome...).
  • Paramètres — position du panneau, sites activés, mots de bruit personnalisés, préférences d'affichage.
  • Historique de matching — journal des correspondances trouvées sur les sites (titre, site, score, date).

Aucune de ces données n'est envoyée à un serveur tiers.

2. Accès aux pages web

L'extension s'exécute sur les sites marchands que vous activez pour :

  • Identifier les cases de mangas affichées à l'écran.
  • Comparer les titres avec votre collection locale.
  • Afficher un badge de correspondance (pourcentage + nom) sur chaque case.

Le contenu des pages que vous visitez n'est jamais lu, enregistré ou transmis en dehors du contexte de la page affichée. L'extension ne fait qu'observer le DOM pour détecter les mangas et afficher des badges en temps réel.

3. Navigation automatique (synchro)

Lors d'une synchronisation, l'extension ouvre temporairement des onglets vers MangaCollec pour récupérer votre collection, la liste des éditeurs et des genres. Ces onglets sont fermés automatiquement une fois les données récupérées.

4. Stockage et conservation

Toutes les données sont conservées dans le stockage local de l'extension, sur votre appareil. Elles persistent tant que vous ne désinstallez pas l'extension ou que vous ne les videz pas manuellement depuis les options.

  • Suppression manuelle : disponible depuis les options (boutons « Vider la base », « Vider les éditeurs », etc.).
  • Sauvegarde : vous pouvez exporter/importer vos données depuis les options. Le fichier de sauvegarde est généré localement.
  • Désinstallation : toutes les données sont supprimées automatiquement.

5. Partage des données

Aucune donnée n'est partagée avec aucun tiers.

Manga-Bridge n'utilise aucun service de suivi, aucune publicité, aucun analytics, et aucun serveur externe.

6. Open source

Le code source de l'extension est entièrement disponible et peut être audité par quiconque. Aucune fonctionnalité cachée ou malveillante n'est présente.

7. Signaler un bug ou proposer une amélioration

Si vous rencontrez un problème avec l'extension ou que vous souhaitez proposer une amélioration, vous pouvez ouvrir une Issue directement sur GitHub :

🔗 github.com/frinox/manga-bridge/issues

Les contributions sont les bienvenues — signalez des bugs, proposez des fonctionnalités, ou améliorez le code vous-même via une Pull Request.

8. Contact

Pour toute question concernant cette politique ou vos données, contactez-nous via les Issues GitHub ou les avis et commentaires du Chrome Web Store.
